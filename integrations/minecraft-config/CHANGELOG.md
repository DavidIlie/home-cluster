# Changelog

## 0.2.0

- Added a dedicated Whitelist tab.
- Added editing of `whitelist.json` from the Minecraft Config page.
- Added UUID preservation and resolution for whitelist entries.
- Added live whitelist reload/apply support when the server is running.
- Added editable unknown and modpack-specific `server.properties` entries in Advanced.
- Added Server Management API controls for newer Minecraft versions.
- Added Server Code of Conduct support and `codeofconduct/en_us.txt` editing.

## 0.1.0

- Initial release.
- Added a tabbed GUI for common `server.properties` settings.
- Added grouped controls for general, gameplay, world, network, RCON/query, performance, resource pack, and advanced settings.
- Preserved unknown properties when saving.
